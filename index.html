01 / EMBEDDED SYSTEMS + POWER ELECTRONICS

ChantSat-1 3U CubeSat Demonstrator

OVERVIEW

Led end-to-end development of the first physical model built for Coastal Carolina University’s 3U CubeSat program, progressing from basic Arduino experience through system architecture, breadboard validation, perfboard integration, testing, and public presentation.

INTEGRATED FUNCTIONS

  • Switchable solar and wall-power operation
  • Rechargeable battery with MPPT charge controller
  • Voltage and current telemetry displays
  • MicroSD data logging
  • ESP32 Bluetooth image reception
  • TFT display simulating a satellite “selfie stick” payload

02 / MECHANICAL DESIGN + TOOLING

Laser Engraver Fixture

OVERVIEW

Designed and built an adjustable laser engraver fixture from 3D-printed components, metal guide rods, bearings, and threaded adjustment hardware. The design moved from a whiteboard sketch to CAD, a first build, and an improved revision.

ITERATION HIGHLIGHTS

  • Vertical adjustment through a lead screw and handwheel
  • Parallel guide rods with bearing-supported motion
  • Horizontal extension for laser-head positioning
  • Revised printed geometry after prototype evaluation
  • Added laser-head shield to protect onlookers

OVERVIEW

A stylized 3D browser game and mobile experience built around exploration, character encounters, and platforming. It evolved from a 2D handheld-style concept through a block-style 3D beta to its current low-poly look.

04 / COMPACT ELECTRONICS

Compact USB On/Off Control PCB

OVERVIEW

Designed, ordered, assembled, and validated a compact inline USB control PCB. The connected device stays powered off and only receives power while the momentary button is held.

PROJECT FOCUS

  • Compact board outline and connector placement
  • USB input and output integration
  • Normally-off momentary pushbutton operation
  • PCB ordering, assembly, and soldering
  • Functional power testing with a live device
